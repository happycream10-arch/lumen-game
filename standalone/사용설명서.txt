LUMEN — 별빛 수집가 / 실행·배포 안내

1. 포함된 게임
48종 오리지널 생물과 6등급, 총 288종 카드. 같은 생물의 등급별 일러스트는 공유됩니다.
미니게임 3종, 코인·별가루, 팩 개봉, 희귀도 보장, 도감·제작·목표 보상, 2인 방 코드 대결.
자체 회원가입·로그인·계정 복구·서버 저장. 각자 기기와 계정으로 접속할 수 있습니다.
현금 구매와 현금 교환은 없습니다.

2. 내 컴퓨터에서 바로 실행
Node.js 24 LTS가 필요합니다. 공식 설치 주소: https://nodejs.org/
압축을 풀고 Windows는 start.cmd, macOS/Linux는 터미널에서 ./start.sh를 실행하세요.
브라우저에서 http://localhost:3000 을 여세요.
다른 기기에서는 서버 컴퓨터의 주소 http://컴퓨터의내부IP:3000 으로 접속하세요.
같은 네트워크에 연결되어 있어야 하며, 운영체제 방화벽에서 3000 포트가 허용되어야 합니다.
압축 안에 이미 빌드된 게임이 들어 있어 npm 설치나 빌드는 필요하지 않습니다.
서버 컴퓨터가 켜져 있고 실행 중이어야 다른 사람이 접속할 수 있습니다.

3. 서로 다른 계정으로 플레이
각자 아이디를 만들고 로그인하세요. 계정마다 처음 600코인을 받습니다.
가입 직후 표시되는 복구 코드를 따로 보관하세요. 비밀번호를 잊었을 때 사용합니다.
오른쪽 위 프로필에서 대결에 표시할 이름을 바꿀 수 있습니다.
한 명이 '친구와 대결'에서 방을 만들고, 상대가 같은 페이지에서 6자리 코드를 입력합니다.
각자 팩을 열어 5팩의 희귀도 점수 합계로 승부합니다. 팩당 240코인, 총 1,200코인입니다.
부족한 코인은 미니게임에서 모을 수 있습니다. 뽑은 카드는 각자의 도감에 남습니다.
다른 기기로 옮길 때는 같은 서버 주소에서 같은 아이디로 로그인하세요.

4. 인터넷 공개 배포
이 파일 자체는 공개 웹 주소가 아닙니다. 본인 소유의 Docker 실행 가능 서버와 도메인이 필요합니다.
서버에 폴더 전체를 올린 다음 .env.example을 .env로 복사하고 LUMEN_DOMAIN에 도메인을 넣으세요.
도메인의 DNS가 해당 서버를 가리키고 80·443 포트가 열려 있어야 합니다.
폴더에서 docker compose up -d --build 를 실행합니다.
포함된 Caddy 설정이 HTTPS를 처리하고, 게임 데이터는 lumen-data 볼륨에 저장됩니다.
서버를 업그레이드할 때 데이터 볼륨을 삭제하지 마세요.
Vercel 등 임시 파일시스템 기반 서버리스에는 이 SQLite 실행본을 그대로 배포하면 안 됩니다.
그 환경에서는 영구 데이터베이스 연결을 추가해야 합니다.
계정 또는 유료 서버 생성은 이 작업에서 대신 수행하지 않았습니다.

5. 저장과 백업
직접 실행: data/lumen.sqlite 및 동일 폴더의 SQLite 보조 파일.
Docker 실행: lumen-data 볼륨.
안전한 백업은 서버를 정상 종료한 뒤 data 폴더 또는 볼륨 전체를 복사하는 방식입니다.
아이디·비밀번호 해시는 서버에 저장되고 로그인 세션은 HttpOnly 쿠키를 사용합니다.
데이터를 삭제하면 계정과 컬렉션을 복구할 수 없습니다.

6. 검증한 내용과 남은 출시 절차
실제 SQLite 저장·서버 재시작, 회원가입·로그인·복구·로그아웃, 계정 분리,
같은 계정의 기기 간 이어하기, 5팩 대결 완료, 보상·재료화·제작·확정 보장,
중복 요청 처리, 허위 인증 헤더 및 다른 사이트의 변경 요청 차단을 검증했습니다.
실제 HTTP 서버의 화면·이미지·로그인·저장 경로도 검증했습니다.
이 실행본은 웹 게임입니다. Steam 설치 프로그램·상점 등록·Steamworks 연동은 포함하지 않습니다.
실제 모바일/데스크톱 브라우저 화면 검수, 부하 테스트, 상용 출시 심사는 완료하지 않았습니다.
미니게임은 캐주얼 게임으로, 클라이언트 정확도 보고를 완전히 방지하는 경쟁용 부정행위 방지 시스템은 아닙니다.
